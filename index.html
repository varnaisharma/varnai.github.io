Cyclistic Bike-Share Analysis

How can a bike-share company convert casual riders into annual members?

I cleaned the source data in Excel, analysed historical ride data in SQL, and built an interactive Tableau dashboard to identify behavioural differences and shape a targeted membership strategy.

SQLTableauExcel
View dashboard ↗View SQL code ↗

Key insights

  1. 01Casual riders take longer trips on average, indicating more leisure-oriented use and an opportunity for experience-led membership messaging.
  2. 02Casual ridership is strongest on weekends, making weekend campaigns, ride bundles, and local-event promotions especially relevant.
  3. 03Members ride more consistently across the week, so conversion messaging should emphasise routine travel value, convenience, and membership savings.
