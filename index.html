CASE STUDY

Data Analysis · Tableau Dashboard

Cyclistic Bike-Share Analysis

How can a bike-share company convert casual riders into annual members?

I cleaned the source data in Excel, analysed historical ride data in SQL, and built an interactive Tableau dashboard to identify behavioural differences and shape a targeted membership strategy.

SQL Tableau Excel
View Dashboard ↗ View SQL Analysis ↗

Project Outcome

The analysis revealed clear behavioural differences between casual riders and annual members. Casual riders tend to take longer and more leisure-oriented trips, particularly during weekends, while annual members use the service more consistently throughout the week.

Based on these findings, Cyclistic has an opportunity to convert casual riders into annual members through targeted weekend campaigns, membership messaging focused on convenience and savings, ride bundles, and promotions linked to leisure activities and local events.

Key Insights

  1. 01 Casual riders take longer trips on average, indicating more leisure-oriented use and an opportunity for experience-led membership messaging.
  2. 02 Casual ridership is strongest on weekends, making weekend campaigns, ride bundles, and local-event promotions especially relevant.
  3. 03 Members ride more consistently across the week, so conversion messaging should emphasise routine travel value, convenience, and membership savings.

Tools Used: Excel · SQL · Tableau Public

CASE STUDY

Data Analysis · Smart Device Usage

Bellabeat Smart Device Usage Analysis

How can Bellabeat use smart device data to better understand user activity patterns and encourage healthier habits?

I cleaned and prepared Fitbit data in Excel, performed data analysis using SQL and Python, and created an interactive Tableau Public dashboard to identify patterns in activity levels, sedentary behaviour, and smart device usage.

Excel SQL Python Tableau Public
View Dashboard ↗ View SQL Analysis ↗ View Python Analysis ↗

Project Outcome

The analysis revealed that users demonstrate moderate levels of daily activity but spend a significant portion of their day sedentary. Users averaged approximately 6,547 daily steps and nearly 995 sedentary minutes per day, highlighting an opportunity for Bellabeat to encourage more consistent movement.

The findings suggest that Bellabeat can move beyond passive health tracking by providing personalised activity goals, sedentary reminders, day-specific notifications, and integrated sleep and activity insights to support healthier and more consistent wellness habits.

Key Insights

  1. 01 Users averaged approximately 6,547 daily steps, indicating moderate activity levels and an opportunity to encourage more consistent movement.
  2. 02 Users spent approximately 995 minutes per day sedentary, highlighting a strong opportunity for movement reminders and inactivity alerts.
  3. 03 Light activity accounted for significantly more time than high-intensity exercise, suggesting that personalised and progressive activity goals could improve user engagement.

Tools Used: Excel · SQL · Python · Tableau Public
