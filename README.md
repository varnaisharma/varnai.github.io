# Portfolio site setup

This is a plain HTML/CSS GitHub Pages portfolio. Copy `index.html` and `styles.css` into the root of the `varnai.github.io` repository, replacing its existing homepage files only after saving a backup.

Before publishing, review the contact and experience information in `index.html` and adjust it if anything changes.

Then commit and push the files to the repository's publishing branch (normally `main`). With the current repository name (`varnai.github.io`) under the `varnaisharma` account, GitHub Pages will serve the homepage at `https://varnaisharma.github.io/varnai.github.io/`.

To publish at the shorter address `https://varnaisharma.github.io/`, rename the repository to `varnaisharma.github.io` in GitHub repository Settings before enabling GitHub Pages.

The Tableau dashboard and `Cyclist_Trips_SQL_Codes.sql` links are already connected to the featured project.
